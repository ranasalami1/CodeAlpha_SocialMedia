# CodeAlpha Social Media Platform

A full-stack social media platform developed as part of the CodeAlpha Full Stack Development Internship.

## Features

- User Registration
- Login / Logout
- User Profiles
- Create Posts
- Comments
- Like / Unlike
- Follow / Unfollow
- Followers and Following Counts
- Responsive Modern UI

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- Django

### Database
- SQLite

## Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Go to the project folder:

cd CodeAlpha_SocialMedia

Create a virtual environment:

python -m venv venv

Activate it:

venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Run migrations:

python manage.py migrate

Start the server:

python manage.py runserver

Open:

http://127.0.0.1:8000/

## Project Purpose

This project was created to practice full-stack web development using Django, authentication, database relationships, and responsive frontend design.
